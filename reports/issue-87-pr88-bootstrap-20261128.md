# Markdown 用語検査の導入候補

他のリポジトリに用語検査を導入する [Issue #87](https://github.com/ssaattww/CodexSkill/issues/87) の候補です。[PR #88](https://github.com/ssaattww/CodexSkill/pull/88) を継続し、現行の既存設定・公開処理は変更しません。CodexSkill 自身への導入は別件です。

| 確認 | 結果 |
| --- | --- |
| 既定の動作 | 読み取りだけ。明示導入では対象コミットを照合し、固定7件または任意CI付き8件。既存先を拒否する |
| 途中失敗 | 自分が作った識別済みの物だけを片付ける。確認済みだった親がいなくなった場合は再作成せず停止する |
| 診断 | ログが揃わない場合は成功扱いしない。設定・入力・Git の取得に失敗した結果を未登録語候補と区別する |
| 隔離 Linux | 導入口、失敗・拒否、監査・強制・対象指定、既存の構成検証を確認した |
| 通常レビュー | 隔離候補に対する既存必須指摘を解消。統合後の正式な確認とは別 |

同じ導入口を使う Windows の実行、任意で追加する検査用 CI と成果物の実行結果、統合版に対する独立レビューは未確認です。既存の利用先にはまだ適用しません。
